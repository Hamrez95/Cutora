## خلاصه اجرایی

ایده اصلی **ساخت رقیب DaVinci یا CapCut نیست**. محصول یک لایه گردش‌کار و اتوماسیون روی ابزارهای بالغ و موتورهای موجود است. مسیر مطلوب: «وصل‌کردن دوربین → شناسایی و ایمپورت خودکار → بکاپ تأییدشده و کتابخانه قابل جست‌وجو → انتخاب/پیشنهاد سکانس‌ها → Quick Edit → زیرنویس → خروجی‌های چندنسبتی → صف پست و انتشار تأییدشده → گزارش عملکرد». تمام پردازش‌های پایه باید تا جای ممکن آفلاین اجرا شوند.

## اصل‌های قطعی و محدودیت‌ها

- فایل اصلی بدون اجازه کاربر **هرگز حذف، جابه‌جای تخریبی یا overwrite نمی‌شود**.
- تولید محتوا نباید بازسازی خانه، شغل یا زندگی روزمره را مختل کند.
- برنامه باید بدون API و اینترنت برای ایمپورت، آرشیو، پخش و تدوین پایه کار کند.
- انتشار مستقیم به حساب شبکه اجتماعی فقط با OAuth/مجوز رسمی، بازبینی قبلی و گزارش وضعیت قابل اتکا.
- «اتوماتیک» یعنی پیش‌نویس خوب و قابل اصلاح؛ نه قول پیدا کردن قطعی بهترین صحنه.
- هزینه‌ها، محدودیت APIها، دسترسی منطقه‌ای و زمان توسعه **نیازمند راستی‌آزمایی** هستند.

## محیط واقعی استفاده

- **کامپیوتر اصلی:** Intel Core i5 نسل ۱۴، NVIDIA RTX 4060، رم DDR5 32GB.
- **ذخیره‌سازی:** SSD سامسونگ ۱ ترابایت اصلی + SSD MSI یک ترابایت + هارد اکسترنال ۱ ترابایت که بخشی از آن پر است. ظرفیت خالی دقیق تعیین نشده.
- **سایر دستگاه‌ها:** Surface Pro با منابع محدودتر؛ گوشی‌های Galaxy A55 و A53 با فضای محدود.
- **دوربین:** خرید GoPro HERO10 یا HERO11 Black استوک در دست بررسی؛ هنوز مدل قطعی نشده. HERO10 امکان نصب عمودی با پایه ۹۰درجه دارد؛ HERO11 انعطاف برش 8:7 بهتری دارد. خرید Insta360 X5 فعلاً به خاطر هزینه کنار گذاشته شده.
- **جنس محتوا:** روایت بازسازی خانه ۲۰ساله، ویدئوهای کاپلی با ماسک ابرقهرمانی، ASMR ابزار/آشپزی، رفت‌وآمد و موتورسواری، ویدئوهای کوتاه، فیلم بلند قبل/بعد، آشپزی و محصولات خانگی در آینده.
