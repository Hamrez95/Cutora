## رویکرد تحویل

به‌جای توسعه یک اپ بزرگ، در هر مرحله یک مسیر واقعی و قابل تست تحویل داده شود. معیار Done: نرم‌افزار نصب‌شونده Windows، فایل آزمایشی واقعی GoPro، سناریوهای شکست و گزارش تست. **طراحی یا صرفاً ساخت تسک به معنی پیاده‌سازی نیست.**

## Phase 0 — Tech Spike (P0)

- نمونه فیلم 4K/5.3K از HERO10 و HERO11 و حالت تایم‌لپس؛ تست USB/MTP و کارت‌خوان.
- تست FFprobe، thumbnails، seek/playback و proxy، پردازش H.264/HEVC و NVENC/CPU روی i5 نسل ۱۴، RTX 4060 و رم 32GB.
- تست برش افقی به 9:16 و فونت/زیرنویس فارسی و عملکرد PySide6 در یک پنجره نمونه.
- اندازه‌گیری import حجیم و رندر ریلز ۳۰ ثانیه‌ای؛ ثبت عملکرد و مشکلات.
**Gate:** اگر USB مستقیم ناپایدار است، کارت‌خوان مسیر اصلی شود؛ اگر preview Qt کند است، UI/stack بازبینی شود.

## Phase 1 — Import / Archive / Backup (P0)

- شناسایی منبع، wizard اولین اجرا، یک دکمه Import، کپی امن و قابل‌ادامه، checksum/duplicate check.
- کتابخانه ایندکس‌شده با تاریخ، thumbnail و status، بکاپ دوم روی هارد مستقل با pending state.
- مدیریت کمبود فضا، خطا، قطع USB، هارد بکاپ غایب، crash و retry.
**Gate:** ۲۰ فایل جدید پس از دو بار Import تکرار نشوند، بکاپ قابل restore باشد و پرونده ناقص اشتباهاً سالم گزارش نشود.

## Phase 2 — Quick Edit + Export (P0)

- Library سریع، انتخاب کلیپ، trim/reorder، عنوان و صدا، پروژه قابل ذخیره.
- سه خروجی جداگانه 9:16، 4:5، 16:9 با پیش‌نمایش crop و batch render.
- Setup.exe واقعی و اجرای برنامه روی ویندوزی که Python نصب ندارد.
**Gate:** از پنج کلیپ یک Reel ۳۰–۴۵ ثانیه‌ای با سه خروجی سالم و بدون کشیدگی تولید شود.

## Phase 3 — Subtitle / Smart Assist (P1)

- زیرنویس فارسی آفلاین (Whisper family) با ویرایش متن و timestamp، فایل SRT و burn-in اختیاری.
- جست‌وجوی transcript، صحنه‌بندی سبک، پیشنهاد AI داستانی/هیجانی/ASMR و خروجی JSON قابل تأیید.
**Gate:** نمونه فارسی واقعی با کلمات محاوره‌ای و چند گوینده تصحیح‌پذیر باشد؛ با قطع API حالت دستی همچنان فعال بماند.

## Phase 4 — Content Management & Publishing (P1 مشروط)

- افزودن ویدئوهای نهایی که خارج از HomeVlog ادیت شده‌اند به Ready Library.
- کپشن هوشمند، cover، برنامه زمانی، صف محتوا، تأیید انسانی، وضعیت منتشرشده یا خطا.
- اتصال رسمی به Buffer یا Meta/YouTube بعد از تأیید مستندات، نیاز حساب/پلن، دسترسی و مدل میزبانی ویدئو.
**Gate:** پست تکراری در retry منتشر نشود؛ اگر انتشار API ممکن نیست، export و کپی کپشن و reminder با کیفیت بماند.

## Phase 5 — Insight & Long Form (P2)

- آمار معتبر API، مقایسه ASMR و ولاگ و بازسازی، تشخیص نرخ تعامل، پیشنهاد موضوع آتی با ذکر عدم قطعیت.
- پیشنهاد سکانس فیلم بلند از کل روند بازسازی؛ مونتاژ نهایی در DaVinci.

## QA: سناریوهای شکست اجباری

- قطع کابل وسط import، تغییر drive letter، تغییر فولدر دوربین، card read-only، نام تکراری، فضای ناکافی، copy interrupted.
- هارد بکاپ متصل نیست، بکاپ corrupted، برنامه هنگام render crash می‌کند، source بیرون از archive حذف شده.
- HEVC، فریم‌ریت‌های متفاوت، ویدیوی عمودی با metadata چرخش، تایم‌لپس طولانی، فایل بدون صدا و فایل خراب.
- متن زیرنویس فارسی/اعداد/انگلیسی مخلوط، اصلاح بعد از trim، پر شدن safe area، سوژه بیرون کادر 9:16.
- retry نشر در قطع اینترنت، وضعیت pending اشتباه، OAuth منقضی، جلوگیری از دو پست یکسان.

## تخمین: آنچه می‌دانیم و نمی‌دانیم

در بحث اولیه حدود ۶۰۰ هزار تا ۱.۵ میلیون توکن برای هسته و مجموع ۱.۲ تا ۳.۳ میلیون برای امکانات هوشمند حدس زده شد، ولی **این تخمین اندازه‌گیری‌شده نیست**؛ نباید مبنای تصمیم مالی شود. زمان و توکن دقیق را با یک Tech Spike و ثبت مصرف هر milestone برآورد کنید.

- هدف: کمترین توکن Codex با spec محدود، استفاده از ابزارهای آماده، تست اتوماتیک، fixture ثابت، patchهای کوتاه و عدم بازنویسی UI/کد بدون نیاز.
- هزینه‌های واقعی احتمالی: زمان توسعه، ذخیره‌سازی، API هوش مصنوعی اختیاری، API یا پلن انتشار، اینترنت و نگهداری.
- پیشنهاد پایه: از همان روز اول با CapCut Desktop برای انتشار واقعی کار کنید و توسعه HomeVlog را به مسیر بحرانی بازسازی خانه گره نزنید.

## KPI برای سنجش ارزش

- دقیقه از اتصال کارت تا آرشیو مطمئن، زمان انسان برای پیدا کردن ۱۰ لحظه خوب، زمان ساخت ریلز قابل انتشار، نرخ خطای Import/Backup/Render، تعداد کلیک، زمان بازبینی و هزینه API به ازای ویدئو.
- اول ۲–۳ روز ضبط واقعی baseline روش دستی را اندازه بگیرید؛ بعد هدف عددی تعریف کنید.
