# موکاپ‌های پیشنهادی HomeVlog Studio

نام نهایی محصول اکنون **Cutora / کاتورا** است. این PNGها نسخه‌های اصلی جهت بصری‌اند و نام HomeVlog Studio داخلشان عمداً به‌عنوان سابقه طراحی حفظ شده؛ رابط پیاده‌سازی‌شده باید Cutora را نمایش دهد. ساخت محصول از [START.md](../../../START.md) و تصمیمات جاری انجام می‌شود.

این سه تصویر، طرح مفهومی با ابزار داخلی Imagegen هستند؛ برنامه اجراشده، اتصال دوربین، فایل واقعی کاربر یا قابلیت پیاده‌سازی‌شده را نشان نمی‌دهند. اطلاعات و تصاویر داخل رابط نمونه‌اند. متن کامل دستورهای تولید در [PROMPTS.md](PROMPTS.md) ثبت شده است.

زبان بصری پیشنهادی: زمینه گرافیتی، رنگ نعنایی برای اقدام اصلی، کهربایی برای هشدار، تصویرهای گرم از محتوای واقعی زندگی؛ منوی راست، حروف فارسی پیوسته و نام فایل/timecode چپ‌به‌راست. این طرح جهت بصری پیشنهادی است و هنوز به‌عنوان design system نهایی تصویب نشده.

در بازبینی تصاویر، خوانایی کلی و تمایز وضعیت‌ها مناسب بود. پیش از پیاده‌سازی باید تراز راست همه تیترها، ترتیب راست‌به‌چپ مراحل، ثابت‌بودن جای آیکن‌ها و تطابق thumbnail انتخاب‌شده با کارت‌های منتخب یکسان‌سازی شوند؛ تصویر مولد مشخصات پیکسلی قطعی نیست. قالب موشن و زیرنویس در صفحه دستیار، گزینه آینده مشروط به آزمون DaVinci هستند.

موشن در تصویر ثابت قابل نمایش نیست. پیشنهاد اجرایی برای مرحله مجاز بعد: transition کوتاه پنل، feedback انتخاب کارت و progress واقعی، همراه حالت کاهش حرکت. فایل کد، prototype یا محصول در این مرحله ساخته نشده است.
