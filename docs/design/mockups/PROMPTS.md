# پرامپت‌های موکاپ HomeVlog Studio

روش ساخت: ابزار داخلی Imagegen؛ بدون CLI یا API key. سه تصویر مستقل با دستور طراحی مشترک ساخته شدند. تصاویر مرجع از فایل‌های شخصی کاربر استفاده نمی‌کنند.

Create a polished, highly usable, high-fidelity desktop Windows application screenshot concept for HomeVlog Studio, a Persian-language media workflow companion for a couple creating home-renovation, cooking, ASMR and motorcycle vlogs. English product names, filenames and timecodes remain left-to-right. Right-hand vertical navigation around 220px wide: HomeVlog Studio at top; labels exactly "ورود و بکاپ", "کتابخانه", "دستیار داوینچی", "آماده انتشار"; quiet "تنظیمات" at bottom. Main content to its left. Show a small unobtrusive "طرح مفهومی" badge so this cannot be mistaken for a real connected application. This is one single coherent screen, not a collage. All thumbnails are illustrative stock-style imagery, not actual user footage.
