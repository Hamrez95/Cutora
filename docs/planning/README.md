# HomeVlog Studio: بسته تصمیم پیش از توسعه

تاریخ: ۲۸ اکتبر ۲۰۲۶، منطقه زمانی Asia/Tehran. وضعیت: **پیشنهاد برای تأیید؛ توسعه مجاز نیست.**

## تصمیم پیشنهادی

یک برنامه همراه برای ورود امن، بکاپ و یافتن رسانه بسازیم. تدوین اصلی، کات، موشن و خروجی نهایی در **DaVinci Resolve** انجام شود؛ این انتخاب مطابق درخواست تازه کاربر است. گزینه «دستیار Codex در داوینچی» به‌صورت افزونه مرحله بعد طراحی شود. ساخت تدوینگر اختصاصی، شبکه اجتماعی و موتور AI جامع از محدوده نسخه اول خارج شود.

با توجه به اولویت اعلام‌شده کاربر برای ظاهر بسیار زیبا، موشن، نصب آسان و توسعه‌پذیری، معماری واحد پیشنهادی **Electron + React + TypeScript + Node.js + SQLite + FFmpeg/FFprobe** است. Python وابستگی اجباری نسخه اول نیست. این تصمیم جایگزین پیشنهاد اولیه PySide6 است؛ هنوز تأیید یا آزمون اجرایی نشده است.

مسیر کم‌هزینه روز اول: کارت‌خوان → آرشیو و بکاپ تأییدشده → مرور و انتخاب → DaVinci → خروجی → بارگذاری دستی در Buffer یا ابزار رسمی پلتفرم. API ابری و اشتراک پولی برای MVP لازم نیست.

## وضعیت واقعی

- در Workspace سیستم مبدأ، هنگام بررسی اولیه مخزن Git، کد محصول و AGENTS.md پیدا نشد. این مشاهده تاریخی است؛ checkout فعلی ریپوی Cutora باید مستقل بررسی شود.
- محتوای موجود، آرشیو و گزارش انتقال دوربین است؛ هیچ فایل رسانه‌ای در این مرحله تغییر نکرد.
- صفحه اصلی Notion و هر پنج زیرصفحه خوانده شد. زیرصفحه دیگری در محتوای بازیابی‌شده دیده نشد؛ فهرست منابع در [SOURCES.md](SOURCES.md) است. اسناد Notion ویرایش نشدند.
- دوربین اکنون HERO10 Black است؛ عبارت «هنوز خریداری نشده» در سند ۲۲ اکتبر قدیمی است.
- سیستم هدف در طرح: i5 نسل ۱۴، RTX 4060، رم ۳۲GB. سیستم این نشست: Windows 11 Home x64، رم حدود ۱۶GB و Intel Iris Xe. هیچ benchmark روی RTX 4060 انجام نشده است.
- آخرین بررسی این نشست: فضای خالی C حدود ۲٫۲۴GB و D حدود ۲۶٫۴۸GB به واحد ده‌دهی؛ این اعداد مربوط به سیستم فعلی‌اند، نه سه دیسک سیستم هدف.
- انتقال قبلی ۵۷ فایل با حجم ۹٬۵۶۰٬۳۱۳٬۳۶۶ بایت و تطابق SHA-256 ثبت شده است. **این انتقال یک کپی سالم است؛ بکاپ مستقل دوم در این نشست مشاهده نشده.** در آن مأموریت قبلی، رسانه دوربین با اجازه صریح کاربر حذف شد. این سابقه سیاست حذف محصول آینده نیست.

## قاعده ادامه کار

موکاپ‌های تصویری افزوده‌شده در درخواست بعدی کاربر: [سه صفحه پیشنهادی رابط](../design/mockups/README.md). این تصاویر صرفاً جهت بصری‌اند؛ اختیار اجرای فعلی در START و تصمیمات جاری تعیین شده است.

جلسه بعد ابتدا این فایل، OPEN_DECISIONS و معیارهای Gate مربوط را بخواند. هیچ قابلیت این گزارش «پیاده‌سازی‌شده» یا «تست‌شده» محسوب نمی‌شود، مگر مشاهده انتقال قبلی که با محدودیت‌هایش ثبت شده است. قدم بعدی فقط پس از تأیید صریح کاربر، یک Tech Spike محدود است؛ تأیید بررسی، مجوز ساخت تمام MVP نیست.
