# تصمیمات باز و Gate تأیید

## مواردی که با اطلاعات تازه حل شدند

- دوربین در استفاده فعلی HERO10 Black است؛ پیشنهاد خرید HERO10/11 در Notion دیگر وضعیت فعلی نیست.
- اولویت UI اعلام‌شده، ظاهر بسیار زیبا با موشن، ساخت/نصب آسان و توسعه‌پذیری است؛ پیشنهاد نهایی از PySide6 به Electron/React تغییر کرد.
- تدوین اصلی، کات، موشن و زیرنویس بنا به درخواست کاربر در DaVinci انجام می‌شود؛ timeline داخلی از پیشنهاد MVP حذف شد.
- گزینه کنترل DaVinci با Codex باید بررسی و در محصول به عنوان آپشن در نظر گرفته شود؛ **درخواست بررسی، تأیید اجرای آن در این مرحله نیست.**

## سؤال‌های نیازمند تصمیم کاربر

| ID | تصمیم | پیشنهاد مشخص | چه چیزی را مسدود می‌کند؟ |
|---|---|---|---|
| D01 | ابزار همراه + DaVinci یا الزام همه‌چیز یک‌کلیک | همراه کوچک، تدوین در Resolve، agent اختیاری | تصویب scope MVP |
| D02 | کدام Spike اول؟ | اگر هدف اصلی agent است، R0/R1 با سقف ۸–۱۶h؛ وگرنه import/installer با همان سقف | ترتیب سرمایه‌گذاری بعدی |
| D03 | کارت‌خوان مسیر اصلی قابل قبول است؟ | بله؛ USB مستقیم P1 مشروط | دامنه importer و زمان |

| D05 | Free یا احتمال خرید Studio | ابتدا Free و آزمون رسمی؛ فقط بعد از نتیجه R0 درباره Studio تصمیم | کنترل خارجی Resolve |

| D07 | مسیر و فضای واقعی دیسک بکاپ | تعیین هارد مستقل و ظرفیت آزاد؛ برای خام فعلی هم نسخه دوم | قابلیت ادعای بکاپ و حذف آینده |
| D08 | بودجه زمان هفتگی و سقف هزینه | ابتدا یک Spike محدود، سپس سقف جدا برای MVP | تبدیل ساعت به تاریخ و کنترل scope |

این سؤال‌ها برای ثبت تصمیم‌اند؛ درخواست پرسیدن هم‌زمان همه آن‌ها در چت نیست. در ادامه فقط D01/D02 و اجازه شروع Spike اول لازم است؛ مسیر بکاپ/دستگاه باید پیش از همان آزمایش تعیین شود. رنگ/نام برند، افکت‌های بیشتر و Analytics مسدودکننده نیستند.

## موارد فنی که هنوز اثبات نشده‌اند

- edition/version نصب‌شده Resolve، عملکرد scripting داخلی/خارجی، پوشش subtitle و Fusion API و کیفیت فارسی.
- توان GPU/codec و زمان ASR روی RTX 4060؛ سیستم این نشست جای آن نیست.
- round-trip XML/EDL، نرخ فریم کسری، templateهای موشن و relink دستگاه دوم.
- پایداری WPD/MTP در قطع/وصل و دسترسی هم‌زمان؛ انتقال موردی موفق کافی نیست.
- فضای خالی سیستم هدف و استقلال فیزیکی دیسک‌های انتخابی.
- قابلیت دقیق API Buffer برای Analytics، مجوز و محدودیت نسخه Meta و حساب واقعی، eligibility سرویس و محدودیت منطقه‌ای.
- زمان و توکن کالیبره‌شده توسعه؛ برآوردهای ROADMAP تا Spike برنامه‌ریزی اولیه‌اند.

## اقدام بعدی پیشنهادی

۱. از خام فعلی یک بکاپ مستقل تهیه شود؛ این گزارش عملیات بکاپ تازه انجام نداده است.
۲. کاربر پیشنهاد scope و Spike اول را تأیید کند.
۳. فقط پس از تأیید، تصمیمات تأییدشده ثبت و workspace کد، Git، dependency و fixture مجاز آماده شود. Git اکنون ایجاد نشده است.
۴. Spike با سقف زمان، شاهد واقعی و گزارش هزینه پایان یابد. موفقیت آن به‌تنهایی مجوز اجرای همه roadmap نیست؛ برای ادامه MVP طبق دامنه توافق‌شده تصمیم گرفته شود.

## پرامپت آماده ادامه: فقط Spike

> اسناد docs/planning را بخوان. فقط تصمیمات صریحاً تأییدشده کاربر را مبنا بگیر. در شاخه/مسیر کد مورد توافق، Spike انتخاب‌شده را با سقف ۸–۱۶ ساعت اجرا کن. فایل خام read-only و fixture از کپی مجاز باشد. اگر مسیر Resolve انتخاب شد، ابتدا edition/version و README محلی را بخوان و یک اتصال فقط‌خواندنی و سپس پروژه کپی پنج‌کلیپی را طبق R0/R1 آزمایش کن؛ Studio را نخر، حسابی متصل نکن و پروژه اصلی را تغییر نده. اگر مسیر import انتخاب شد، نصب Electron/SQLite/FFmpeg و ورود/verify/restore یک مجموعه محدود و دستگاه دوم را ثابت کن. نتیجه واقعی، ناتوانی‌ها، زمان و مصرف را گزارش کن و پیش از توسعه بزرگ متوقف شو.

## پرامپت آماده پس از Gate موفق و اجازه MVP

> بر اساس گزارش Spike و ADRهای تأییدشده، فقط P0های MVP_SCOPE را در iterationهای کوچک بساز. هر task یک معیار پذیرش و شاهد اجرا داشته باشد. UI React/RTL با قرارداد IPC محدود؛ انتقال/DB در worker؛ هیچ raw حذف یا overwrite نشود. DaVinci تدوینگر اصلی باقی بماند؛ P1های agent/ASR/USB/API را بدون تأیید دامنه وارد P0 نکن. هر milestone با نصب واقعی، تست‌های ایمنی مربوط و گزارش موارد باقی‌مانده تمام شود.

## وضعیت توقف

در این مأموریت فقط بررسی و مستندات انجام شده است. هیچ کد Production، scaffold، dependency نصب‌شده، cloud، API پولی، account connection، benchmark یا ادیت DaVinci ایجاد/اجرا نشده. **ادامه اجرایی منتظر تأیید صریح کاربر است**؛ این Gate از درخواست خود کاربر در متن مأموریت آمده است.
